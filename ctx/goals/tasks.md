## Deliverable 3 — Entire local world-event alert application (approved task inventory)

**Human-defined goal:** build the entire local application described in frozen `ctx/goals/plan.md`, not a demo or one-source subset. This is **one** requested whole-application deliverable, with its own approved task inventory. The human chooses which task to work on next; this approval does not mean work has begun or settle the open decisions identified in the tasks. Do not promise worldwide completeness or 24-hour retrieval on the strength of a single feed probe.

Every task contributing to implementation must leave tangible evidence under `docs/` (logs and/or screenshots relevant to its work), use `src/` for code and tests and `out/` for produced artifacts, update the feature-to-unit/integration-test inventory when applicable, and document each implemented user-facing feature in the user guide as it arrives.
